# Dashboard brief for implementation phase 7

Dark charcoal background, restrained amber accent, readable typography. One screen.
Top: Hive wordmark, repository, active agents, unresolved findings, connection status.
Left: agent cards with task, workspace, current intent revision and heartbeat status.
Center: selected conflict, precise evidence, affected symbols and proposed interface.
Right: contract lifecycle and each agent's acknowledgement of the exact version.
Bottom: chronological evidence events and test result with command + exit status.

Always distinguish 'potential overlap', 'incompatible assumption', 'agreement accepted'
and 'implementation verified'. A green badge requires corresponding evidence.
No decorative swarm animation that obscures the problem. No fabricated activity.
Empty/offline/stale/model-unavailable states are required. Render code and messages
as text, not untrusted HTML. Keep model API keys out of frontend code.
