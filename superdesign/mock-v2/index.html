Hive web prototype

A clickable prototype with mock data. No backend is wired in this phase; a typed mock module stands in for the API and compiles against the real Hive types.

What it shows

  • A Hive server reachable on a public cloud link, so members join from anywhere.
  • Sign in with a token kept in session storage, and invite links that carry the token in the URL fragment.
  • A three-step connect flow: workspace, invite with a one-time token and config snippet, and a live checklist.
  • An overview with agent progress and one current conflict explained in plain language, with evidence and a proposed declaration.
  • Ghost Contracts with proposed, accepted, implemented and verified states, signatures on exact versions and verification runs.
  • An activity timeline scrubbed with the table-of-content rail, and member and token management.
  • Empty, offline, stale and model unavailable states, in light and dark themes, at 390, 820 and 1440 px.

Sign in

Paste a token once. It is kept in session storage only.

Join from an invite link

Invite links carry the token in the URL fragment, so it never reaches the server.

Connect, step 1: workspace

The cloud link, repository, revision and index status, with a copy button.

Connect, step 2: invite

Pick a member, a role and a client.

Connect, step 2: token and config

The token is shown once, with a ready config snippet that includes the cloud link.

Connect, step 3: waiting

The checklist ticks as the server is reached, the client is configured and the first agent registers.

Connect, step 3: done

The first agent has registered.

Overview

Agent progress, the current conflict in plain language, the proposed declaration and the agreements rail.

Agreements

Ghost Contracts with their lifecycle state.

Agreement detail

Lifecycle, exact-version signatures, the declaration, verification runs and history.

Activity

A chronological timeline with the table-of-content rail as a scrubber.

Activity: diff event

The selected event shows its diff as text.

Activity: test output event

The selected event shows the test command output as text.

Members and tokens

Create, label, set a role, see last use and revoke. The admin bootstrap token is never shown.

Required states

Empty, offline, stale and model states, shown in the light theme at 1440 px.
